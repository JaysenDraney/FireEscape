# FireEscape

An open source TV launcher for Android TV and Google TV, built around a plugin system.

**Status:** early development. The project scaffold and test harness are in place (milestone M0.1), and the plugin form and transport are decided ([ADR 0004](docs/adr/0004-plugin-form-and-transport.md)). The [roadmap](website/src/content/docs/project/roadmap.md) lists the milestones and what is next.

## What is here

- [docs/plugin-system-proposal.html](docs/plugin-system-proposal.html): the plugin system design proposal. It is a single standalone HTML file. Download it and open it in a browser, because GitHub shows the source instead of rendering it.
- [docs/adr/](docs/adr/README.md): architecture decision records.
- [website/](website/): the docs site (Astro Starlight), including the roadmap.

## Open decisions

The remaining open questions are listed in section 6 of the proposal and in the roadmap's Still open table.
